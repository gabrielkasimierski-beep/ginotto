# Voz — Ginotto Burger

> Cómo habla esta marca. Todo texto que se escriba para este cliente (web, app, placas) sale de acá.
> Lo que sale del Instagram del local se marca "(IG)" y queda a confirmar con Gaby.

| | |
|---|---|
| **Tono** | Cercano, directo, de barrio y con humor. Street, no corporativo. |
| **Tratamiento** | Vos (español rioplatense) |
| **Palabras que sí** | plancha · oficio · burga · las mejores que vas a probar · pedí · smash · cheddar (IG) |
| **Palabras que no** | soluciones integrales · brindamos · experiencia gastronómica · líderes en el mercado · "Bienvenidos a nuestro sitio web" |
| **Una frase que suena a ellos** | "Las mejores que vas a probar." · "Hamburguesas como deben ser." (IG) · "Ojalá haigas encontrado una mejor que yo." (IG, confirmar) |
| **Una frase que NO suena a ellos** | "Ofrecemos una propuesta gastronómica de excelencia para el paladar más exigente." |

El humor es parte de la marca, pero **cada chiste lo aprueba Gaby antes de publicarse**.
